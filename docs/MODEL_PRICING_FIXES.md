# 模型价格覆盖修复与验证

日期：2026-09-20。

## 修复结果

| 问题 | 修改后的行为 |
| --- | --- |
| 添加 `starry/` 等前缀可绕过精确规则 | 对精确匹配和价格查询统一规范化已知前缀，保留 OpenAI fast 后缀兼容。 |
| 同优先级的通配符压过精确规则 | 优先级越小越优先；同级按单个模型、系列、厂商、通配符排序，通配符按非星号字符数降序排列。最终以匹配表达式、规则 ID 稳定排序。 |
| 填写 `gpt`、`gpt5` 无法对整个系列定价 | 这类文本仍是精确 ID，不会隐式变成前缀。新增厂商默认倍率和系列覆盖入口，按目录元数据覆盖当前及未来模型；单模型编辑器会提示未匹配的精确 ID。 |
| 自定义别名按不相关模型的估算价格计费 | 优先核对模型自身的官方价格，没有则解析配置的目标模型；不再使用模型家族、厂商或全局中位数猜价。目标循环不会卡住目录。 |
| 内置兼容路由目标覆盖模型自身价格 | 有官方价的模型直接使用自身价格，避免 GPT 等模型被旧兼容路由目标的价格覆盖。 |
| 旧固定总价实际扣费与目录报价不一致 | 固定总价、分项固定价、官方价倍率均通过同一个解析结果产生展示和扣费报价。旧通配符固定价不再被展示层忽略。 |
| 编辑其他规则时丢失旧单价或无法保存 | 前端保留全部原始总量、输入、输出和缓存单价字段。转换为倍率需要显式确认；取消弹窗不修改原规则。 |
| 保存期间启动的旧刷新覆盖新缓存 | 以缓存版本阻止旧查询回填；保存后重新读取数据库，订阅时才获取价格快照。 |
| 总价默认展示和小额价格精度不清楚 | 模型列表默认展示总量参考价；小额非零价格不再显示成零，详情提示实际分项计费。 |

示例：打包价格表中的 GPT-5.5 输入为 5 USD / MTok，输出为 30 USD / MTok。
设置倍率 0.1 后，输入为 0.5，输出为 3；各使用 100 万 Token 时合计扣费 3.5。
目录展示的总量参考价为 1.75 / MTok，表示输入和输出各占一半，不是将输入价和输出价相加。
规则倍率替代默认倍率，不与默认倍率重复相乘。

无可核实价格、也无旧固定价规则时，目录显示「待定价」，计费请求在余额预留和上游调用之前返回
`503 MODEL_PRICE_UNAVAILABLE`。管理员应同步官方价格、配置正确的目标模型，或通过兼容 API 配置明确单价。
本次没有自动改写数据库中的既有规则；旧规则的转换和删除仍由管理员执行。

## 界面调整

- 默认倍率和生效规则数量放在顶部，官方数据源默认折叠。
- 「厂商与系列」可直接设置 OpenAI 等厂商的默认倍率，再对 GPT-5 等系列单独定价；重置图标恢复继承，全局保存一次提交。
- 后端新增 `scope: model | provider | family`，旧规则默认仍为 `model`。厂商归属来自请求的目录模型，不跟随跨厂商路由目标。
- 规则列表支持搜索、启停、编辑、删除、撤销草稿和恢复默认。
- 草稿价格预览展示生效规则、其他命中规则、官方来源模型、官方价与实际价。
- 预览复用后端匹配逻辑，不在浏览器另写一套价格算法，也不保存草稿。
- 编辑或切换模型立即使旧预览失效；数据源同步失败保留未保存的规则。
- 手机和平板按内容容器宽度重新排版，操作按钮和模型 ID 不溢出。
