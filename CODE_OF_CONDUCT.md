# Code of Conduct

Starry API adopts the **Contributor Covenant, version 2.1** as its code of conduct. The full text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and is incorporated here by reference; it applies in every space of this project (issues, pull requests, discussions, reviews) and whenever someone represents the project in public.

In short: be respectful, welcome people of every background and experience level, give and accept feedback graciously, and focus on what is best for the community. Harassment, personal attacks, discriminatory language, publishing other people's private information, and other conduct that would reasonably be considered inappropriate are not acceptable.

## Reporting and enforcement

If you see or experience behavior that breaks this code, report it to the maintainers privately with GitHub's **Report content** tool on the comment, issue or pull request. The maintainers keep the repository's *reported content* setting on so that these reports reach them directly. Please include links and context. Reports are handled in confidence, and the maintainers follow the Enforcement Guidelines of the Contributor Covenant (correction, warning, temporary ban, permanent ban) when they decide what to do.

Security vulnerabilities are not conduct reports; see [SECURITY.md](SECURITY.md).
